# Parihaka single-head K6 without distillation

These twelve YAMLs define the MAE, Barlow Twins and Random zero-distillation
arms of the [shared v1 extension](../../../hmm_v1/zero_distillation_ablation_v1/README.md).
The original source-specific K6 targets, training recipe, decoder settings and
test supports are inherited. See the shared matrix, runbook and validation
record for execution, complete-grid aggregation, and recovery.
