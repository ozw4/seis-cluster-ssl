# F3 unanimous XY-neighbour hard-label artifact producers

This experiment applies one synchronous source-label correction only where all
valid same-z XY neighbours agree on a different label: 4/4 with four valid
neighbours and 3/3 with three.

Run the numbered stages from `01` through `06`: target export and audit,
smoke/full pretraining, embedding extraction, then validation. The stage files
own their executable settings and output locations.
