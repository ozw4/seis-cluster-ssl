# Volve single-head K6 without distillation

These twelve YAMLs define the MAE, Barlow Twins and Random zero-distillation
arms of the [shared v1 extension](../../../hmm_v1/zero_distillation_ablation_v1/README.md).
The explicit single-head source route retains the original parent, K6 targets,
five-horizon decoder, sample window and test supports. See the shared matrix,
runbook and validation record for execution, complete-grid aggregation, and
recovery.
